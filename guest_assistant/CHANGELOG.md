## 0.8.0

- Guests can add the guest page to their home screen as an app, with the
  Guest Assistant icon. On Android and desktop this needs the guest port
  behind HTTPS; on an iPhone it is Share → "Add to Home Screen". The app
  also opens when Guest Assistant is out of reach and reconnects on its own.
- New "App name" on the Settings tab: the name under the app's icon. Set it
  before guests install the app; an iPhone keeps the name it was added with.
- After an update, open guest pages and installed apps reload onto the new
  version on their own. Pages opened before 0.8.0 need one manual reload.
  The guests' settings dialog shows the version.
- Browsers keep the guest page's files and only download them again when
  they change, so the page loads faster.
- Map cards on guest dashboards get the map worker they need again; the
  guest page was missing it since 0.7.1.

## 0.7.0

Changes from a security review:

- Guests only see the services they may call. The entity registry they get
  no longer contains unique IDs, which are often MAC addresses or serial
  numbers.
- Images of rows, badges and picture elements are checked like those of
  picture cards. Media players only play media that an action on the
  dashboard plays.
- Visibility conditions only tell guests true or false, never the error
  text of a template.
- Each guest connection is limited in how many commands, subscriptions and
  pending requests it can have.
- Signing out ends the tokens and connections of that device.
- The guest page is sent with a Content-Security-Policy.
- Session cookies are marked secure behind a reverse proxy that sends
  `X-Forwarded-Proto: https`.
- The app runs as an unprivileged user, and only that user can read its
  data.
- Standalone: wrong setup codes are throttled and a code expires after an
  hour; the admin page shows the address you sign in at before sending you
  to Home Assistant.
- Switching to another Home Assistant revokes Guest Assistant's token in the
  old one.

Fixes:

- The Run button in a script's more-info dialog works for guests.
- Update entities show their release notes. Media players no longer offer
  media browsing, which guests cannot use.
- Guests see an error instead of an endless spinner when their dashboard
  does not finish loading.

  you. Only dashboards generated by a strategy are still rejected.
- New Guest Assistant logo and icon.
