# Guest Assistant

## Getting started

1. Start the app. On the first start it creates its own Home Assistant user
   without admin rights and uses only that one. Nothing has to be set up.
2. Open "Guest Assistant" in the sidebar (administrators only).
3. Dashboards: add the dashboard guests should get. Guest Assistant analyses it
   and hides cards it cannot check, for example custom cards, from guests;
   the admin page lists them as issues. Dashboards generated by a strategy
   cannot be added at all. Some cards raise questions, such as web links or
   media players that can be grouped; until you answer, the restrictive
   choice applies.
4. Guests: add a guest, choose the dashboard and pass on the username and
   password. Switch a guest off while they are not visiting.
5. Guests open `http://<home-assistant-host>:3123`.

Guests always open port 3123: the app uses host networking (for the
companion app's discovery, see below), so the port cannot be changed under
"Network".

## Companion app

Guests can also use the Home Assistant app on their phone instead of the
browser. It is off by default:

1. Settings tab: switch on "Allow the companion app". From then on Guest
   Assistant answers the app like a Home Assistant server would.
2. Optional: switch on "Show in the app's server list on this network", so
   the app lists Guest Assistant (under the app name) when a guest adds a
   server at home. Or send guests the link shown there, which opens the app
   with Guest Assistant filled in.
3. Guests sign in with their guest username and password and see their
   dashboard. Their phones show up on the Guests tab, where you can sign a
   phone out.
4. Optional, per dashboard on the Dashboards tab: "Widgets in the companion
   app" lets guests put the dashboard's entities on widgets, device
   controls and their watch.

The app's sensors, location tracking and notifications are not used:
whatever it sends is acknowledged and dropped. Assist is not offered. Behind
HTTPS on a public address the app skips its questions about the home
network. Switching the companion app off signs every guest out of the app.

## Good to know

- A dashboard is a permission: guests get exactly the entities on it. Editing
  the dashboard in Home Assistant changes what guests can access right away.
- The guest port is not behind Home Assistant's login. Before you make it
  reachable from the internet, put it behind HTTPS (for example a reverse
  proxy) and set the guest address on the Settings tab.
- Guests change the language in their settings dialog. The choice stays on
  their device.
- Guests can add the guest page to their home screen as an app (Android and
  desktop: "Install app" in the browser menu, which needs the guest port
  behind HTTPS; iPhone: Share → "Add to Home Screen"). Set the name under the
  icon on the Settings tab under "App name", before guests install it: an
  iPhone keeps the name it was added with. On an iPhone, guests sign in once
  more inside the app.
- After an update of Guest Assistant, open guest pages and installed apps
  reload onto the new version on their own. The version is shown in the
  guests' settings dialog.

## How it works

- Guest Assistant keeps its own guest accounts. Guest traffic goes to Home
  Assistant with the token of its own non-admin user, and every message is
  checked against the dashboard's entities (default deny).
- The admin page is served through ingress. It only answers requests from the
  Supervisor and lets only Home Assistant administrators in.
- "Recreate the Guest Assistant user" on the Settings tab replaces its Home
  Assistant user, for example after it was deleted.
