# Guest Assistant

Give guests their own login to exactly one Home Assistant dashboard.

Guests sign in with a username and password you create for them and see one
dashboard. They can see and control only the entities on it: no other states,
history, cameras or service calls get through. You pick the dashboards and
manage guests on the app's admin page in the sidebar.

Alpha: try it at home first, see the Documentation tab before you expose the
guest port to the internet.
